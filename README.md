# Weather Dashboard

A Windows desktop application built with Visual Basic .NET that provides real-time weather information and forecasts.

## Features

- **Real-time Weather Data**: Display current weather conditions for your location
- **Weather Forecasts**: View weather predictions for upcoming days
- **Location Search**: Search and add multiple locations to track
- **User-friendly Interface**: Intuitive Windows desktop application
- **Quick Updates**: Refresh weather data on demand

## Requirements

- Windows operating system
- .NET Framework (version compatible with Visual Basic .NET)
- Internet connection for weather data retrieval

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/Weather-Dashboard.git
   cd Weather-Dashboard
   ```

2. Open the project in Visual Studio
3. Build the solution
4. Run the application

## Usage

1. Launch the Weather Dashboard application
2. Enter a city name or location to search for weather information
3. View current weather conditions and forecasts
4. Add multiple locations to your dashboard for quick comparison
5. Click refresh to update weather data
